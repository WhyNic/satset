# SatSet

SatSet adalah sistem antrean virtual berbasis WhatsApp yang dirancang untuk membantu pelanggan mengurangi waktu yang terbuang saat mengantre di bazaar atau restoran.

## Latar Belakang

Masyarakat masih sering menghabiskan banyak waktu untuk mengantre di berbagai layanan, khususnya pada bazaar makanan yang memiliki banyak tenant.

## Solusi

SatSet memungkinkan pengguna untuk:

- Melihat kondisi antrean restoran
- Melihat estimasi waktu tunggu
- Mengambil antrean secara virtual
- Mendapatkan tiket antrean digital
- Menerima notifikasi melalui WhatsApp
- Mendapatkan rekomendasi restoran serupa dengan antrean yang lebih singkat

## Cara Kerja

1. Pengguna membuka SatSet
2. Memilih restoran
3. Melihat jumlah antrean dan estimasi waktu
4. Mengambil antrean
5. Dialihkan ke WhatsApp
6. Mendapatkan nomor antrean digital
7. Menerima notifikasi ketika giliran mendekat

## Prototype

Prototype dibuat menggunakan Figma untuk mata kuliah Venture Creation.

## Business Model

SatSet menggunakan model B2B dengan target:

- Restaurant / tenant
- Bazaar
- Event organizer

Sumber pendapatan dapat berasal dari biaya langganan merchant dan paket penggunaan untuk event.

## Technology

Konsep teknologi yang digunakan:

- WhatsApp Business Cloud API
- Webhooks
- Cloud Database
- Real-time Queue Management
